# 0.5.3.6.8 filename and UTF-8 fixes

Base v0.5.3.6.7. Both RPG engines remain SA.
- Main FAT32 fallback uses explicit utf8=1, second-card exFAT uses iocharset=utf8. UTF-8 locale in boot, SSH/SMB and RPG launch, without changing existing passwords. Added glibc 2.41 Korean/Japanese/Western converters and generated C.UTF-8 from existing Bootlin toolchain. No kernel replacement or original game filename changes.
- EasyRPG preserves valid UTF-8 filenames even without ZIP UTF-8 flag, supports CP949/CP932 legacy names and per-game filename encoding selection, existing case-insensitive directory index enhanced for legacy names.
- MKXP normalizes resource lookup keys using ICU NFC and Unicode case folding; raw on-disk paths preserved. UTF-8 Ruby defaults; explicit legacy filename encoding option. Read-only resource File.open/new/read/binread/existence and directory lookup adapter, restricted to existing game resource roots via native resolver. Writes and non-resource paths unchanged. Native stop timeout skips unsafe GL/audio teardown if RGSS thread is unresponsive.
- Both firmware roots: C.UTF-8 locale, CP949/EUC-KR/CP932/SHIFT_JIS/UTF-16LE/CP1252/CP437 iconv round trips passed. Actual Dropbear/SFTP server under isolated ARM64 firmware: Korean directory and 2 MiB file upload/list/download/rename/delete, key/password lifecycle passed on both.
- EasyRPG engine-linked image probe: real PNG decode passed 10/10 (folder with decomposed Hangul and mixed case, UTF-8 ZIP, unflagged UTF-8 ZIP, CP949 ZIP explicit/auto) on both firmware roots.
- MKXP synthetic RGSS1 script: UTF-8 filesystem, NFC request to NFD mixed-case image, CP949 image request, direct Ruby read using different case, Korean save and clean exit passed under QEMU ARM64 Mesa. Initial direct read failure fixed; initial quit before first frame caused a shutdown crash; guard added, normal post-frame quit retested successfully. Actual reported game/menu and physical device remain unverified.
- Korean table 2901 entries, scanner and ARM64 UI build passed. Actual hardware exFAT/FAT32 mounts and SMB transfer are not reproduced by these tests. SFTP tested on isolated tmpfs. Legacy archive filename detection may be ambiguous: use per-game Korean CP949 option if auto fails.
- Sources and build scripts archived with glibc toolchain provenance, upstream glibc source and existing SA engine/runtime sources. No proprietary game/RTP content. Existing non-RPG emulators untouched.
