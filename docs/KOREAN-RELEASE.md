# BananaOS 한국어판

- 기반: BananaOS 0.5.3.6. 한국어판 버전은 0.5.3.6.1부터 시작합니다.
- 메뉴, 시스템 설정, 파일 관리자, 게임 패널 및 번역 리소스를 사용하는 에뮬레이터 메뉴의 한국어 번역을 추가했습니다.
- 기존 언어를 보존하며, 한국어를 기본 언어로 선택합니다. 파일명, 검색 및 게임 제목에 두벌식 입력을 지원합니다.
- OTA는 dj5927/BananaLinux의 GitHub 릴리스를 사용합니다. 원본 비공개 베타 채널 및 업데이트 캐시를 분리했습니다.

## 0.5.3.6.2 — SSH / SFTP

- 원본 최신 공개 베타 v0.5.3.6 (커밋 1ebc80c8b545098f23c3bee97f58fe71415469c3)의 수정 사항을 유지합니다.
- 설정 > 네트워크 > 파일 공유 > SSH 비밀번호에서 8~63자의 영문, 숫자, 기호 비밀번호를 설정하고 SSH / SFTP를 켭니다.
- WinSCP, FileZilla: SFTP, 기기의 Wi-Fi IP, 포트 22, 사용자 root, 설정한 비밀번호를 입력합니다. 개인키 등록은 선택 사항입니다.
- SSH 기본 상태는 꺼짐이며, 비밀번호를 설정하지 않으면 기존 공개키 인증만 허용합니다. SSH 공개키 전용 항목으로 비밀번호를 삭제할 수 있습니다. 비밀번호는 카드에 솔트가 포함된 SHA-512 crypt 해시로 저장하며 SMB 공유에서 숨깁니다.
- 신뢰하는 로컬 네트워크에서만 SSH를 켜고 인터넷에 포트 22를 노출하지 마세요. root는 기기 전체에 접근합니다. 시스템 파티션은 읽기 전용이고 게임과 설정은 /data에 있습니다.
- 0.5.3.6.2는 OTA 전용 증분 빌드로 배포합니다. 기존 SD 카드를 다시 기록하지 않아도 됩니다.

## 설치

기종을 반드시 확인하세요. RG DS에는 rgds, RG DS Plus에는 rgds-plus 파일을 사용합니다.

- 새 카드: 0.5.3.6.1의 해당 기종 img.gz 이미지를 Raspberry Pi Imager v1.9.6으로 기록한 후 OTA로 업데이트합니다. 카드 전체가 지워지므로 데이터를 먼저 백업하세요.
- 기존 BananaOS: 해당 기종의 update.tar 파일을 데이터 파티션의 banana/updates에 복사하고 설정 > 시스템 > 업데이트에서 설치합니다. 기존 언어가 명시적으로 설정된 경우 설정에서 한국어를 선택하세요.
- SHA256SUMS 파일로 내려받은 파일의 무결성을 확인할 수 있습니다.
- 한국어판 설치 후에는 한국어판 GitHub 릴리스에서 OTA 업데이트를 확인합니다.

원본 프로젝트의 게임/저장 기능과 A/B 슬롯 업데이트 방식을 유지합니다. 게임 자체의 번역, 별도 앱, 에뮬레이터 코어 내부의 독립 UI는 해당 프로그램의 지원 범위에 따릅니다.

전체 소스 자동 빌드와 QEMU 시스템 부팅 검증은 사용자 모드의 ARM64 실행 및 SSH/SFTP 통합 테스트와 구분됩니다. 증분 OTA는 기존 검증된 커널, 장치 트리, 에뮬레이터를 유지하며 실기기 설치 전 백업을 권장합니다.
