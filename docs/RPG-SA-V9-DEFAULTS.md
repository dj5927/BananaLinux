# 0.5.3.6.9 emulator defaults and MKXP diagnostics

Base v0.5.3.6.8. Standalone EasyRPG and MKXP are retained.
- Settings > Other systems > Emulators has 16 entries, including the existing DS, Game & Watch, PICO-8, FBNeo and both native RPG engines. A opens the system's default options. Existing core selection is inside the new page. DS's original SuperDrastic/BananaDS settings and per-system buttons remain accessible.
- Shared defaults in /data/banana/emulator-defaults.conf. RPG games inherit defaults unless a per-game value is set. Explicit Auto is distinct from inheritance. CP949 can be set once for EasyRPG (text/filename encoding) or MKXP filename encoding. Existing nonempty per-game values retained. Defaults reset with emulator settings reset.
- Libretro systems have core, applicable frontend, panel/screen, shader/border, audio latency, VSync (RetroArch), integer scale, quick resume and existing button settings. Global fallback preserved. The original core-specific and game-specific RetroArch overrides remain higher-level settings; this is not an exhaustive export of every libretro core option. PICO-8's common options apply to Fake-08, not the separately supplied official executable. Game & Watch gets audio and view options.
- MKXP log beside the actual project: banana-mkxp.log, previous log banana-mkxp.previous.log. Read-only/unavailable folder uses the old private path; /data/banana/logs/rpg-last-log-path.txt always records current path. Restart appends to the same session. Effective settings logged.
- Native MKXP exception handling no longer assumes an array/nonempty Ruby backtrace or modifies Ruby-owned strings. Full available exception details are logged, native failures return nonzero, no desktop exception dialog. The exact user's item/status menu failure has not been reproduced or diagnosed.
- QA: both headless ARM64 resolutions passed all 16 page A/B navigation, CP949 default save and inherited RPG choices. New defaults help text fits; reviewed representative Korean screenshots. Actual launch scripts tested in isolated target firmware with final emulator/hardware boundaries stubbed: scoped RetroArch values and global restore, BananaFront flags, Game & Watch, forced Fake-08. RPG stub tests passed default/per-game/explicit auto precedence and log rotation/restart. MKXP RGSS exception tests run with actual ARM64 engine, QEMU/Mesa software renderer. Physical device and real core override interaction not verified.
- Earlier EasyRPG, RetroArch, BananaFront, FBNeo binaries and UTF-8/SSH changes unchanged. Firmware packaging incremental from verified v0.5.3.6.8, not full Buildroot.
