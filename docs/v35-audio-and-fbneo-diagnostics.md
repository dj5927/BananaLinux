# BananaOS Korean v0.5.3.6.35

Doukutsu-rs의 일시정지 후 무음 복구를 시도하는 수정과 FBNeo 성능 진단 기록을 추가했습니다. 실제 기기의 사운드 복구와 VF 속도 개선을 확인한 버전은 아닙니다.

- **Doukutsu-rs**: CPAL의 ALSA 오류 처리에서 재개 후 underrun/suspend 상태가 남는 경우, 게임의 오디오 스레드에서 복구하도록 했습니다. 공식 `Doukutsu-rs.sh`에만 적용하며 다른 포트·기존 Mali/Panfrost 설정·SDL 경로는 유지합니다. 이 수정은 v34에는 없었고 이번 버전에 처음 포함됩니다.
- **FBNeo**: v34의 참조 코어 파일을 유지합니다. 프론트엔드나 코어 교체만으로 차이가 없었다는 테스트 결과를 반영해 추가 속도 설정은 강제로 바꾸지 않았습니다.
- FBNeo 실행 초반 30초 동안 몇 차례 CPU/GPU 클럭, 온도, 프로세스 CPU 사용량·코어 경로, 관련 설정 파일의 옵션을 `/data/banana/logs/fbneo-diagnostics.log`에 기록합니다. 다음 실행 시 이전 기록은 `.previous.log`로 보관합니다. 계정·인증 항목은 제외합니다. 설정 기록은 파일의 값이며, 없는 키는 코어 기본값을 사용합니다.
- v31의 슬립 수정, 커널/DTB, 에뮬레이터 실행 파일, 세이브와 게임별 GPU 선택은 유지합니다.

검증: 사운드 복구 12개 상태의 native/ARM64 검사와 음소거 대조군, 실제 정지·재개 신호를 사용하는 PCM 모의시험, 포트 생명주기 및 적용 범위 4개 검사, 진단 기록의 필터/파일 해제/종료·PID 재사용/설정 보존 검사. RG DS/Plus 모두 전체 파일 차이·커널/DTB 동일성·체크섬·ARM64 코어 로딩·패널 통신·GPU 설정 복구·오프라인 업데이트 검사를 통과했습니다.

테스트: Doukutsu-rs에서 문제가 나던 방식으로 일시정지·재개 후 소리를 확인해 주세요. VF는 같은 설정으로 30초 이상 실행한 뒤 종료하고 `fbneo-diagnostics.log`를 전달해 주세요. 포트 로그 위치는 `/data/banana/logs/ports/last-log-path.txt`에 기록됩니다.
